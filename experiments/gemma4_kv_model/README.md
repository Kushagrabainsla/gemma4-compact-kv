# gemma4_kv_model (shared code only)

This folder holds only three code files of experiment E-55: `run_e55.py`, `splice_e55.py` and `analyze_e55.py`.
Later experiments (E-56, E-57, E-58, E-59 and E-65 to E-73) import them.

E-55 itself is not part of this release. It is INVALID by its own rule, and the paper does not use it. Its data file
held private text, so its data, results and notes are left out.
